# 05｜短内容与推文线程模板（X / Twitter）

> 目标：把长文能力压缩成“可传播的颗粒”。  
> 原则：**先给结论，再给证据，最后给方法**。

## 1. 微内容的三种价值

1. **洞察**：一句话改变读者的看法（反常识/重新命名）
2. **证据**：用图或对比把洞察钉住（最强）
3. **方法**：读者立刻能用（规则、清单、步骤）

---

## 2. 单条推文模板（适合日更）

### 模板 A：反常识一句话 + 解释

```
你以为 {常识} 会带来 {结果}。
但真正决定 {结果} 的其实是 {变量}。
（一句话解释 + 一个例子）
```

### 模板 B：定义一个新词（“命名即控制”）

```
我把这种穿法叫做「{新词}」：
- {特征1}
- {特征2}
- {特征3}
它的优点是 {优势}，风险是 {误区}。
```

### 模板 C：三点清单（信息密度最高）

```
判断一件 {单品} 是否“{审美判断}”，我只看 3 个细节：
1) {细节A}
2) {细节B}
3) {细节C}
只要第 2 条不成立，后面都白搭。
```

## 3. 线程（Thread）模板（强推荐：8–12 条）

> 线程的本质：**带读者完成一次“看懂”**。  
> 最常用节奏：Hook → 证据 → 解释 → 迁移 → 误区 → 总结。

### 模板 1：一张图讲清一个概念（8 条）

1. Hook：`{结论}`（读者想收藏）
2. 放图（或对比图）：`{图片说明}`  
3. 定义变量：`{变量}` 是什么（通俗解释）
4. 解释 A：`{图中A}` 为什么成立
5. 解释 B：`{图中B}` 为什么不成立（或另一种成立）
6. 迁移：普通人怎么用（按场景）
7. 误区：最常犯的 1 个错（提醒）
8. TL;DR：3 条总结（可截图）

### 模板 2：对比式线程（10–12 条）

1. Hook：同一个 `{问题}`，`{A}` 与 `{B}` 给出相反答案
2. A 的特征（配图/例子）
3. A 的优点（适用场景）
4. A 的风险（误区）
5. B 的特征（配图/例子）
6. B 的优点（适用场景）
7. B 的风险（误区）
8. 对照表（强烈建议截图/表格）
9. 选择建议：身材/气质/预算
10. 结尾：一句“审美判断”收束（提升格调）

### 模板 3：教程式线程（“怎么选/怎么搭”）

1. Hook：`{对象}` 最重要的不是 `{表象}`，而是 `{尺度}`
2. 你要解决的场景：`{通勤/旅行/约会}`
3. 规则 1（例子）
4. 规则 2（例子）
5. 规则 3（例子）
6. 3 个价位/3 个风格推荐（可选）
7. 常见坑（最有价值）
8. TL;DR

## 4. 配图策略（微内容的胜负手）

### 4.1 最有效的 4 类图片

1. **对比图**：同款不同廓形/同色不同材质/同场景不同重心
2. **细节图**：领口、肩线、袖山、裤褶、面料肌理
3. **三连图**：同一件单品 3 种叙事（通勤/周末/夜晚）
4. **结构图**：用简单线条标出重心、比例、轮廓边界

### 4.2 图片说明模板（让图变成证据）

```
看图时只盯 1 个变量：{变量}。
左图 {A}：{解释}
右图 {B}：{解释}
结论：{一句话}
```

---

## 5. 排版技巧（让读者“愿意读完”）

- 单条推文：**2–4 行**最佳；每行 12–18 字左右（中文）
- 线程：每条只讲一个点；多用“：”“—”“1) 2)”
- 重要结论：做成 **TL;DR 三条**，方便读者截图/转发

---

## 6. 如何系统性找到“高质量推文/线程”

> 不要刷时间线；要用“可复用搜索法”。

### 6.1 从高质量站点反向找作者

1. 在 `01_sources_high_quality.md` 选一个媒体（如 Aeon / Hyperallergic / Permanent Style）
2. 点开文章作者页/作者署名
3. 通常能在作者主页找到社媒入口

### 6.2 用关键词找“可保存的线程”

建议从这些英文关键词组合开始（因为高质量资料多在英文圈）：

- `tailoring thread`
- `silhouette explained`
- `fabric drape vs structure`
- `aesthetics philosophy thread`
- `art criticism thread`
- `why this outfit works`

筛选标准（满足 2 条以上才收藏）：

- 有图、有对比、有定义（不是空口）
- 结构清晰（编号/分段）
- 有可迁移结论（你能写进模板库）
