# 07｜配图策略与图片检索 Query 模板（英文）

> 目标：让“图片”变成结构的一部分：每个大段都对应一张“证据图/氛围图/对比图”。

> 补充说明：  
> - 本文件更偏“**怎么搜**”（Query 与结构化配图）。  
> - 若你需要“**去哪找精品图库** / **怎么选图** / **版权合规清单**”，请看：[`09_image_libraries_and_selection.md`](./09_image_libraries_and_selection.md)。

## 1. 配图的四种功能（先定功能再找图）

1. **氛围图（Mood）**：把读者带进语境（城市、季节、光线、质感）
2. **证据图（Evidence）**：证明你的论点（对比/细节/结构）
3. **方法图（How-to）**：可迁移（3 套搭配、步骤图、部位标注）
4. **反例图（Pitfall）**：让误区一眼成立（非常有效）

## 2. 图片“结构化”摆放（推荐）

| 文章模块 | 推荐图片类型 |
|---|---|
| 导语 | 氛围图（1 张） |
| 深度解析 | 证据图/对比图（1–2 张） |
| 穿搭实操 | 三连图（3 张）或对比图（2 张） |
| 穿搭误区 | 反例图（1 张） |
| 结语 | 氛围图或“总结图”（1 张，可选） |

## 3. Query 公式（最常用）

### 3.1 氛围图（街拍/编辑部感）

**公式：**
`{color} {silhouette} {item} street style {city} {season}`

示例：
- `neutral palette oversized trench coat street style Paris autumn`
- `monochrome minimalist outfit street style Tokyo winter`
- `tailored navy blazer wide leg trousers street style London spring`

### 3.2 证据图（廓形/比例/材质）

**公式：**
`{item} close up {detail} {material}`

示例：
- `wool coat close up lapel stitching`
- `denim jacket close up selvedge detail`
- `linen trousers close up drape texture`

### 3.3 对比图（同题多解）

**公式：**
`{concept} comparison {A} vs {B}`

示例：
- `silhouette comparison structured shoulders vs soft shoulders`
- `fabric drape comparison silk vs cotton`
- `tailoring comparison Neapolitan vs English suit`

### 3.4 三连图（可迁移穿搭）

**公式：**
`{item} outfit ideas {occasion}`

示例：
- `white shirt outfit ideas office`
- `black loafers outfit ideas smart casual`
- `wide leg trousers outfit ideas weekend`

## 4. “高级感”常用关键词（英文）

> 用来给搜索引擎/图库“定调”，比单写 “fashion” 更有效。

- `editorial`
- `minimalist`
- `quiet luxury`
- `tailored`
- `monochrome`
- `neutral palette`
- `textural`
- `architectural silhouette`
- `clean lines`
- `soft tailoring`

## 5. 负向关键词（帮你避开“电商图”）

在搜索里加：

- `-product`
- `-catalog`
- `-ecommerce`
- `-white background`

示例：
`oversized blazer street style editorial -ecommerce -white background`

## 6. 图片说明模板（让图“服务论点”）

```md
*Image note:* Focus on **{one variable}**.
Left: {A}. Right: {B}.
Conclusion: {one sentence}.
```

## 7. 版权与引用（建议原则）

- 优先使用：可商用图库（如 Unsplash / Pexels）或媒体允许嵌入的图片
- 如果用截图：尽量标注来源链接与作者
- 关键：**图片是证据** → 证据必须可追溯
 - 若涉及跑秀/街拍/编辑部图片：强烈建议先阅读 `09` 中的“版权/合规清单”，再决定是否发布
